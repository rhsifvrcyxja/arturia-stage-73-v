## Overview

Arturia Stage-73 V recreates the Fender Rhodes Suitcase and Stage 73 electric pianos with physical modeling of tine, tone bar, and pickup interactions for authentic electric piano tone.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Stage-73 V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Physical Model** | Tine vibration, damper, and pickup modeling for realistic touch response |
| **Suitcase/Stage** | Both Suitcase and Stage model variants available |
| **Stereo Tremolo** | Authentic suitcase stereo tremolo circuit emulation |
| **Amp+Pedal** | Built-in amplifier and effects pedal simulations |
